# UPI Transactions Data Analysis Dashboard

## Project Overview
This project analyzes UPI (Unified Payments Interface) transaction data to understand payment trends, transaction patterns, and user behavior. The dashboard provides interactive visualizations to help identify key insights in digital payment activity.

## Problem Statement
With the rapid growth of digital payments in India, analyzing transaction data helps businesses and financial institutions understand payment behavior, transaction volume, and usage trends.

## Tools & Technologies
- Power BI
- Excel
- Data Cleaning
- Data Visualization

## Dataset
The dataset contains UPI transaction information including:

- Transaction ID
- User ID
- Amount
- Payment Method
- Bank
- City
- Transaction Date
- Device Type
- Status

## Key KPIs
- Total Transactions
- Total Transaction Amount
- Successful vs Failed Transactions
- Average Transaction Value
- Transactions by Bank
- Transactions by City

## Dashboard Insights

### 1. Transaction Volume
Identifies total number of UPI transactions over time.

### 2. Bank Performance
Shows which banks process the highest number of transactions.

### 3. Payment Method Analysis
Analyzes most used payment methods like QR, Mobile Number, and UPI ID.

### 4. Geographic Analysis
Shows transaction distribution across cities.

### 5. Transaction Status
Compares successful and failed transactions.
