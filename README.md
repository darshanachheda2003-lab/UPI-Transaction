# UPI TRANSACTION ANALYSIS DASHBOARD
# Porject Overview 
This project analyzes UPI (Unified Payments Interface) transaction data to understand transaction trends, bank performance, and payment patterns. The data was cleaned and transformed using Power Query and visualized through an interactive dashboard built in Microsoft Power BI.
The dashboard provides insights into transaction volume, bank-wise performance, and monthly transaction trends to help understand digital payment growth.
# Project Objectives
- Analyze UPI transaction patterns
- Identify top performing banks
- Track monthly transaction growth 
- Understand payment trends in digital transactions
# Tools and Technologies Used 
- Microsoft Power BI- Data visualization and dashboard creation
- Microsoft Power Query- Data cleaning and transformation
- Excel/CSV Dataset- Data source
- GitHub- Project documentation and version control
# Data Preparation 
The raw dataset required preprocessing before analysis. The following steps were performed using Power Query:
- Removed duplicate records
- Handled missing or null values
- Standardized column formats
- Created calculated columns for analysis
- Structured the dataset for dashboard visualization
# Dashboard Features 
The Power BI dashboard includes the following analytics:
- Total UPI Transaction Volume
- Bank-wise Transaction Analysis
- Monthly Transaction Trends
- Payment Mode Distribution
- Interactive Filters for Data Exploration
Users can interact with the dashboard to explore transaction trends and patterns.
