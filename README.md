# UPI-Transaction
upi-transaction using power bi dashboard
Project Overview
This project focuses on analyzing UPI (Unified Payments Interface) transaction data to uncover insights into digital payment trends, user behavior, and transaction patterns across different banks, cities, and payment methods.
Using data visualization and business intelligence techniques, the dashboard helps identify key trends that can support decision-making in the rapidly growing digital payment ecosystem.
The interactive dashboard was built using Microsoft Power BI to transform raw transaction data into meaningful business insights.
